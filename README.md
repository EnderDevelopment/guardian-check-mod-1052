# Guardian Check Mod

Guardian-style player checking with head animation for Fabric 1.21.11

## Features

- Guardian-style head animation during player checks
- /check and /uncheck commands for player interaction

## Requirements

- Minecraft 1.21.11
- Fabric Loader 0.15.7 or higher
- Fabric API 0.96.7 or higher

## Installation

1. Download the mod JAR file from the [releases page](https://github.com/EnderDevelopment/guardian-check-mod/releases)
2. Place the JAR file in your `mods` folder
3. Launch Minecraft with Fabric

## Usage

### Commands

| Command | Description | Permission |
|---------|-------------|------------|
| /check <player> | Check a player with Guardian-style animation | playercheckmod.check |
| /uncheck | Stop checking a player | playercheckmod.uncheck |

### Permissions

- `playercheckmod.check` - Allows players to use the /check command
- `playercheckmod.uncheck` - Allows players to use the /uncheck command

## Configuration

The mod does not have a configuration file. All settings are hardcoded in the mod.
